# Kyle Mabilangan — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and a small amount of JavaScript for the mobile navigation.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `your.email@example.com` with your professional email in the contact section.
3. Replace the LinkedIn placeholder with your actual profile URL.
4. Fill in education details and dates for your Accenture training and IMI internship.
5. Replace sample project cards/descriptions with your actual work. Add only screenshots and details you have permission to share.
6. Remove any skill you cannot confidently discuss in an interview.
7. Save and open `index.html` in your browser to preview the site.

## Publish for free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository named `your-github-username.github.io` (replace with your username).
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**. If needed, select deployment from the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. Your URL will be `https://your-github-username.github.io/`.
6. Open the published URL on both desktop and mobile to check the layout and links.

## Alternative quick preview
You can open `index.html` directly in a browser without hosting. For sharing with recruiters, publish it using GitHub Pages or another static website host.

## Notes
- The portfolio uses Google Fonts if the viewer has internet access; fallback fonts are included.
- Project visuals are CSS illustrations, not actual screenshots of your work.
- No resume PDF is linked yet. If you have a resume PDF, add it to the project folder and create a link to it from the hero or contact area.
